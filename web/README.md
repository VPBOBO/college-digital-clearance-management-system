# Staff Website

This is the React website used by the sample office reviewers.

Follow the repository's [Windows setup guide](../SETUP-WINDOWS.md) to install packages and start the backend first.

From this folder:

```powershell
npm ci
npm run dev
```

Open <http://localhost:5173>. Sign in using `reviewer-a` or `reviewer-b`. The local demo password is `test123`.

To create a production build:

```powershell
npm run build
```
