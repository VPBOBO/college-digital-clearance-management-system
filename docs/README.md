## About the requirements baseline

The requirements folder uses fictional examples and placeholders where college-specific information is not confirmed. The actual clearance form (`SRC-FORM`) and institutional policies/interviews (`SRC-INST`) are still listed as not yet available. Do not treat sample offices, names, or rules as official college policy.

## GitHub publication

The repository is already public so the instructor can view project progress. The first follow-up history cleanup is recorded in the publication review note. The full publication-safety review and confirmation of school publication, ownership, and licensing rules are still in progress. No license is included.
